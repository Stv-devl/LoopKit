## The shell protocol (critic M6)
`project_config.py shell <dir>` prints NUL-terminated records:
- `key=value`, one record per list item, for `app_roots`, `protected_branches`, `test_command`,
  `formatter`;
- the scalars `linter`, `module_root`, `tests_root`;
- the pre-rendered EREs, escaped in Python:
  - `protected_dirs_ere`;
  - `protected_dirs_text` (the deny text list `src/, shared/, …`);
  - `env_suffix_ere`, `icons_ere`, `tdd_layers_ere`, `py_target_ere`;
- then a last record `#end=<n>`, where `<n>` counts the records before it.

The loader:
- reads the records from a process substitution with `while IFS= read -r -d '' rec`, which works
  on bash 3.2 and needs no temp file;
- gets the exit status from `wait $!`;
- accepts the result only when the status is 0, `#end` is present, `<n>` matches the count, and
  every required key arrived.

Anything else gives `CWK_CFG_STATUS=3` ("reader output incomplete"). The values go into **fixed
global arrays and scalars** (`CWK_CFG_PROTECTED_BRANCHES=()`, `CWK_CFG_TDD_LAYERS_ERE=…`): no
nameref, no `eval`, no `source`.

## Fail closed without hiding a deny (critic M5)
`cwk_config` sets `CWK_CFG_STATUS`:

| Status | Meaning |
| --- | --- |
| 0 | ok |
| 3 | invalid file, or incomplete reader output |
| 4 | absent file |
| 5 | no absolute `CLAUDE_PROJECT_DIR` |
| 6 | reader not runnable: no python3, or no reader file |

`cwk_config_reason` gives one text naming the file, the cause, `install.sh` and `/kit:init`.

**Pending ask.** A rule that needs a value while the status is not 0:
- does not decide;
- sets `CWK_CFG_PENDING_ASK=1`;
- lets evaluation continue.

Every rule that needs no value still runs, so its deny still wins: `rm -rf ~`, `--no-preserve-root`,
mkfs/dd, `.tdd-red`, `git commit -S`, attribution. Each hook emits the pending ask at the head of its
own ask section, before any other ask, and only when no deny fired. If nothing asks or denies and a
value was missing, the pending ask is still emitted: the hook never passes on a missing value.

| Hook | Where the pending ask is emitted |
